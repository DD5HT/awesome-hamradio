# Contribution Guidelines

Please ensure your pull request adheres to the following guidelines:

+ Search previous suggestions before making a new one, as yours may be a duplicate.
+ Make an individual pull request for each suggestion.
+ New categories or improvements to the existing categorization are welcome.
+ Check your spelling and grammar.
+ The pull request and commit should have a useful title.
+ If unfamiliar with GitHub and just wanting to add changes, please fill out the following form https://forms.gle/XX9zwJXgWZhVwk8k8 and the maintainers will review the proposed additions.

## Entry format

```
+ [Name](https://link) Short description ending with a period.
```

**Requirements:**
- The project must be free and open source.
- The project must be relevant to amateur radio.
- The project must be actively maintained or historically notable.
- The link must be reachable.
- The description must start with a capital letter and end with a period.
- Prefer a single sentence.

**Example:**
```
+ [OpenRTX](https://github.com/OpenRTX/OpenRTX) Free and open source firmware for digital amateur radio devices, designed with modularity and performance in mind.
```

## Where to add your entry

Place your entry in the most relevant section. If no section fits, feel free to propose a new one.

| Section | What belongs here |
|---|---|
| Operating Systems | Linux distros or OS images bundling ham radio software |
| APRS | APRS clients, servers, igates, trackers |
| Networking | Linking protocols and repeater networking software |
| Firmware | Replacement or open firmware for radio hardware |
| Decoding | Signal decoders, voice codecs |
| POCSAG | Paging transmitter/receiver software |
| SDR | Software-defined radio front-ends and signal analyzers |
| Logging | Contact loggers and related tools |
| Digimodes | Digital voice and weak-signal mode software |
| Libraries | Reusable libraries and command-line DSP tools |
| Radio programming | Codeplug editors and programming tools |
| Satellite operation | Satellite tracking and data decoding |
| Training | Exam trainers and operating skill builders |
| Simulation | Electromagnetic and antenna simulation tools |
| Hardware | Open hardware designs for radios, TNCs, and accessories |

## Reporting a broken link

Open an issue with the title `Broken link: <project name>` and include the URL that no longer works.
